# Lab Grader: downloads

Installers for **Lab Grader**, a desktop app for reviewing AI-suggested rubric grades on
group lab reports.

**Download:** open [Releases](../../releases/latest) and get `Lab Grader Setup x.y.z.exe` (Windows).

Windows may warn that the installer is from an unknown publisher because it isn't
code-signed. Choose *More info → Run anyway*. Once installed, the app updates itself:
when a new version is out you'll see a "Restart now" bar at the top of the window.

This repository only holds the installers.
